# Role: research

**Scope (may change):** `docs/`, `experiments/`, `config/`.

**Responsibilities:** experiment protocols, safety gates, evidence write-ups, calibration
notes, and the material for the thesis text.

**Rules**
- Every number must trace back to raw data or a cited run. Mark synthetic data as synthetic.
- Remove private IPs, user paths, credentials and personal data before committing.
- When a doc changes a quest's status or evidence, flag it in `DISCUSSION.md` so the
  `thesis-desk` role can update `thesis_data.json`.

**Done when:** links and paths resolve, sources are cited, and the log entry lists the evidence used.
