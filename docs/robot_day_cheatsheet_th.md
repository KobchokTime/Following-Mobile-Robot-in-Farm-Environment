## กฎความปลอดภัย (อ่านก่อนเริ่ม)

- หุ่นนี้**ไม่มีปุ่มหยุดฉุกเฉิน (E-stop)** · ทดลองเฉพาะในพื้นที่ปิด มีคนเฝ้า (spotter) และทุกคนพร้อมก้าวออกจากทางหุ่น
- จะหยุดหุ่น: กด **Ctrl+C** ที่เทอร์มินัล bringup · bridge เขียนศูนย์ให้ล้อทันทีเมื่อปิด · ถ้าแค่ `/cmd_vel` หยุดส่ง
  ล้อจะเริ่มลดความเร็ว 1 วิหลังคำสั่งสุดท้าย และหยุดราว 1.5 วิ ที่ 0.5 m/s (ราว 2.5 วิ ที่ 1.4 m/s)
- การหยุดทั้งหมดเป็นซอฟต์แวร์ คนเฝ้าต้องอยู่ห่างจากทางหุ่นเสมอ ไม่ว่า log จะบอกอะไร
- **preflight มี FAIL แม้ข้อเดียว = ห้ามขยับหุ่น** หยุดลำดับการทดลองแล้วส่งผลให้ Claude
- ขับครั้งแรกที่ `max_speed_mps:=0.5` เสมอ
- **ก่อน preflight `--live` ผ่าน 0 FAIL (หัวข้อ 3) ล้อต้องลอยจากพื้นตลอด**
- `map_walk` ในหัวข้อ 8 ทำหลังการทดลองหลัก (หัวข้อ 6–7) เสร็จแล้วเท่านั้น

## 2. ยกล้อขึ้น เปิด bridge อย่างเดียว เช็กทิศเลี้ยวและเวลาหยุด (15 นาที)

เป็นการเช็กบนแท่น ล้อลอยจากพื้นตลอดหัวข้อนี้ · เปิด bridge ตัวเดียว (ยังไม่เปิดระบบตามคน):

```bash
python3 ros2_yolo_ws/scripts/MAIN/Control/zlac_joystick_bridge.py --ros-args \
    -p speed_mode:=mps -p max_speed_mps:=0.5 -p wheel_radius_m:=0.085 -p turn_dir:=1.0 -p port:=/dev/ttyUSB1
# เทอร์มินัลที่ 2:
python3 tools/robot_day/turn_check.py
```

- ☐ ขั้น 1 `linear.x = 0.2` → ล้อทั้งสองหมุนไปข้างหน้า
- ☐ ขั้น 2 `angular.z = 0.3` → ล้อขวาไปหน้า ล้อซ้ายถอยหลัง (เลี้ยวซ้าย)
- ถ้าขั้น 2 กลับด้าน ให้ใช้ `turn_dir:=-1.0` (ทั้งคำสั่ง bridge และคำสั่งเปิดระบบทุกครั้ง) · ผล: turn_dir = ______

เวลาหยุดของ bridge (ล้อยังยกอยู่):

```bash
ros2 topic pub -r 10 /cmd_vel geometry_msgs/msg/Twist "{linear: {x: 0.5}}"
# ล้อหมุนแล้ว กด Ctrl+C ที่คำสั่งนี้ แล้วจับเวลาจนล้อหยุด (ถ่ายวิดีโอไว้)
```

- ☐ ล้อหยุดหลังหยุดส่งคำสั่ง ______ วิ (ควรราว 1.5 วิ · เกิน 3 วิ = ห้ามขับ แจ้ง Claude)
- ☐ กด Ctrl+C ที่ตัว bridge ขณะล้อหมุน → ล้อหยุดทันที
- ทั้งสองข้อเป็นการเช็กล้อลอย ยังไม่ได้พิสูจน์ระยะหยุดบนพื้น

## 3. ยกล้อขึ้น เปิดระบบเต็มและ preflight (15 นาที)

ล้อยังลอยอยู่ · ปิด bridge จากหัวข้อ 2 ก่อน (Ctrl+C) · ยังใช้รัศมีล้อ 0.085 (ยังไม่ได้วัด):

```bash
python3 tools/robot_day/preflight.py --max-speed 0.5 --wheel-radius 0.085
ros2 launch ros2_yolo_ws/launch/follow_bringup.launch.py max_speed_mps:=0.5 \
    wheel_radius_m:=0.085 turn_dir:=<1.0 หรือ -1.0> \
    lidar_angle_offset_deg:=0.0 lidar_angle_sign:=-1.0 \
    camera_cmd:="<คำสั่งเปิดกล้อง>" lidar_cmd:="<คำสั่งเปิด LiDAR>"
```

ห้ามใส่ `obstacle_stop:=false` หรือ `avoid_trail:=true` (ค่าเริ่มต้นถูกแล้ว)

เทอร์มินัลที่ 2:

```bash
python3 tools/robot_day/preflight.py --live --obstacle-stop true --avoid-trail false \
    --speed-mode mps --max-speed 0.5 --wheel-radius 0.085 \
    --expect-lidar-angle-offset-deg 0.0 --expect-lidar-angle-sign -1.0 \
    --expect-obstacle-stop-m 0.45 --expect-spin-clear-radius-m 0.40 \
    --expect-max-decel 0.8 --expect-recheck-max-s 1.0
ros2 topic info /scan --verbose
```

- ☐ preflight ขึ้น `ready` และ **FAIL = 0** (WARN ได้, จดไว้) · **ถ้ามี FAIL ห้ามวางหุ่นลงพื้น**
- ☐ `/scan` มีผู้รับของ `follow_stop` แบบ reliability `BEST_EFFORT`
- ☐ log ของ `sync_fusion_node` บรรทัด `[GATE]` มี `lidar_assist=1`
- ☐ ไม่มีบรรทัด `[OBST] on clearance=0.00 m (no fresh scan)` ขณะ LiDAR เปิดและไม่มีอะไรใกล้
- ☐ `t18_angle_post` (หุ่นนิ่ง ล้อลอย): ตรวจ `/scan` ด้วยเสาตรงหน้า → มุมดิบใกล้ 0°; ย้ายเสาไปซ้ายหน้า → มุมดิบติดลบ และ `/lidar_sector_dists` ต้องรายงานทางซ้าย (sector หมายเลขสูง); ยกเสาออกแล้วระยะคืนเดิม
- ☐ preflight อ่านค่าที่รันอยู่จริงของทั้ง `follow_stop_node`, `sync_fusion_node` และ `lidar_sectorizer`: offset 0.0°, sign −1.0 เหมือนกันทั้งหมด · วางเสากลับมาตรงหน้าจึงตรวจ `clr=`; ถ้าค่าหรือทิศไม่ตรง **หยุด** ส่ง log ให้ Claude
- แล้วปิดระบบทั้งหมด (Ctrl+C)

## 4. วางหุ่นบนพื้น เช็กความเร็วด้วย bridge อย่างเดียว (10 นาที)

ระบบตามคนต้องปิดอยู่ (มีผู้ส่ง `/cmd_vel` แค่สคริปต์นี้) · ทำเครื่องหมายที่พื้นตรงกลางหุ่น · เปิด bridge แบบหัวข้อ 2 (ใส่ turn_dir ที่ได้) แล้ว:

```bash
python3 tools/robot_day/speed_check.py --speed 0.4
```

- ระยะที่สคริปต์บอก ______ m · ระยะที่วัดได้จริง ______ m
- รัศมีล้อที่ถูก = 0.085 × ระยะจริง ÷ ระยะที่สคริปต์บอก = ______ m
- ☐ เขียนลง `config/motor_wheel_calibration.md` เป็นบรรทัด `wheel_radius_m = 0.0xx (measured 2026-11-07)`
- แล้วปิด bridge (Ctrl+C)

## 5. เปิดระบบใหม่ด้วยรัศมีล้อที่วัดได้ และ preflight อีกรอบ (5 นาที)

ใช้คำสั่งเดียวกับหัวข้อ 3 แต่เปลี่ยน `wheel_radius_m:=<ค่าที่วัด>` และ `--wheel-radius <ค่าที่วัด>` ทั้งสองคำสั่ง preflight

- ☐ preflight `--live` ขึ้น `ready` และ **FAIL = 0** อีกครั้ง · ถ้ามี FAIL ห้ามขยับหุ่น
- ยังไม่ทดลองให้หุ่นตามเดิน: ไปหัวข้อ 6 ก่อน (เช็กแบบหุ่นนิ่งก่อนแบบเคลื่อนที่)
